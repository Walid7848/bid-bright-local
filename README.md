# Bid Buddy

أريد إنشاء منصة مزايدة للخدمات الحرة. الزبون ينشر الطلب مع الصور، ويستطيع أصحاب المهن في نفس المدينة تقديم عروض أسعار تفاعلية، ويقوم الزبون بمقارنة العروض واختيار العرض الأنسب".
